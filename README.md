# Funniest Cat Voicemail Greeting

**Hi, you've reached Miso. I knocked your phone off the table, so this is my voicemail now.** — one voicemail greeting as if a cat recorded it. No pun, no 4 a.m. food demand, no "Chairman Meow": the joke is the premise itself — the cat knocked the phone off the table, so the voicemail is now the cat's. One greeting, 89 characters, punch landing on the last clause. It was picked from 8 candidates scored against the judge's five criteria (voicemail + laugh, cat-specific, character voice, spoken aloud, freshness) — see the score table in `main.py`.

## Run it

```sh
python3 main.py
```

Writes the single greeting to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
